# Массив - это объект

- Массив - это объект, он наследуется от Object
  - Поэтому массивы создаются через new
  - Поэтому у массива есть методы equals(), toString(), hashCode()
- У всех видов массивов (`int[]`, `String[]` и т.д.) есть скрытые классы, наследники Object
  - У самопальных массивов, вроде `Person[]` тоже будет скрытый класс, наследник Object, который JVM сгенерирует налету

## "Проблема Arrays.asList"

Вот код:

```java
int[] numbers = new int[] { 5, 7, 4, 21, 100 };
List<int[]> list = Arrays.asList(numbers);
```

Меня бесило то, что я передаю массив и получаю `List<int[]>`, т.е. "список массивов" вместо массива чисел. Я не понимал, как так. Да и сейчас не понимаю механику особо. Вот описание метода `<T> asList(T... a)`. Он принимает несколько аргументов. По сути то же самое что `<T> asList(T[] a)`. Здесь дженерики, а они по определению не работают с примитивами. Если передать массив объектов:

```java
Integer[] numbers = new Integer[] { 5, 7, 4, 21, 100 };
List<Integer> list = Arrays.asList(numbers);
```

Тогда получается список этих объектов. А если передать массив примитивов, то тип элемента вычисляется как "Массив-объект".
