

# Настройка подключения к БД

- Настройки писать в файл `src/main/resources/application.yaml`

```yaml
spring:
  application:
    name: ndp
  datasource:
    url: jdbc:postgresql://localhost:5432/имя_базы_данных
    username: admin
    password: admin123
  jpa:
    hibernate:
      ddl-auto: none
    show-sql: true
```

- `ddl-auto`
  - `none` - значит что хибер при запуске приложения не будет проверять, соответствует ли схема БД описанным сущностям. При других значениях он может проверять на соответствие и даже пытаться подогнать БД под сущности и обосрать все, так что none - база.
- `show-sql`
  - `true` - чтобы в консоль приложения выводился sql, который хибер генерирует при работе с БД.
