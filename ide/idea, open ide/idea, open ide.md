# Свернутый код

- Когда открываешь файл, по умолчанию все методы классов свернуты
- Как отключить
  - File > Settings > Editor > General > Code Folding

# Подсказки типов в стримах

- Для элементов стрима и после методов постоянно показывает типы в серых прямоугольниках
- Как отключить
  - File > Settings > Editor > Inlay Hints, отключаем все что надо



# Автоматические отступы, скобки

- Автоматически отступает после Enter, в стримах и т.д., сам закрывает скобки и т.д.
- Как отключить
  - File > Settings > Editor > General > Smart Keys, отключаем все что надо





# Отступ на таб

- Таб или пробелы вместо таба, размер отступов
- Где настроить
  - File > Settings > Editor > Code Style (развернуть) > Java > настройки понятны интуитивно
    - Contiuation indent - двойная падла, выставить 0
