# Liquibase

- Инструмент применения миграций к БД.
- В специальных файлах пишем миграции и при старте приложения, ликвибейз проверяет, что БД соответствует этим миграциям. Если есть новые миграции - вносит изменения в БД. Если есть конфликты - заставляет их решить.
- Основная идея - чтобы миграции были частью кода, чтобы их удобно было хранить в гите и чтобы они были как бы частью приложения.



# Avro

- Schema register
- Формат описания сообщений для кафки, чтобы слать \ читать в кафку четко структурированные сообщения.
- Принцип работы: в специальных файлах описывается структура сообщений. После компиляции из них получаются классы. Клиент кафки настраивается особым образом на работу с ними. При отправке сообщения, в кафку уходит и его схема. За счет этого консюмер может схему считать и десериализовать сообщение в нужный класс.
