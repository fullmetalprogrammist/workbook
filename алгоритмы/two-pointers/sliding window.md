# Minimum Size Subarray Sum

- "Минимальная длина подмассива с заданной суммой"
- Дан массив **положительных целых чисел** `arr` и положительное целое число `target`.
- Нужно найти **минимальную длину непрерывного подмассива**, сумма элементов которого **больше или равна `target`**.
- Если такого подмассива нет — вернуть `0`.

```java
public static int slidingWindow(int[] arr, int target) {
    int left = 0;
    int len = 0;
    int sum = 0;

    for (int right = 0; right < arr.length; right++) {
        sum += arr[right];

        while (sum >= target) {
            int curLen = right - left + 1;
            if (len == 0 || len > curLen) {
                len = curLen;
            }

            sum -= arr[left];
            left++;
        }
    }

    return len;
}
```
