# Устаревшее избранное

- Задача: есть два микросервиса - user и product. У каждого своя база данных. В user хранятся избранные товары пользователей в виде [userId, productId], а в product хранятся описания товаров, например [id, title, price, description] и т.д. 
  - При добавлении в избранное в БД сохраняется [userId, productId], обращение к product для этого не требуется
  - Но при запросе избранного, user обращается к product, чтобы достать title и price товара
  - Чтобы снизить нагрузку на product, реузльтат запроса избранного кэшируется в Redis
- Проблема: сейчас при добавлении нового товара в избранное с кэшем ничего не происходит. Поэтому вновь добавленный товар не отображается при запросе избранного, т.к. возвращается закэшированный результат, в котором нового товара нет. Какие варианты решения проблемы?
